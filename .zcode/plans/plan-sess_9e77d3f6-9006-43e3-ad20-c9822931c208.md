## Fix Vietnam Map - Clean SVG với hiệu ứng đẹp

### Vấn đề hiện tại
- MapLibre GL hiển thị xấu trên landing page
- Bo tròn không cần thiết
- Cần bản đồ đơn giản, sạch sẽ

### Giải pháp
**1. Tạo Vietnam SVG path chuẩn**
- Lấy path SVG từ một nguồn đáng tin cậy
- Hoặc tạo path đơn giản nhưng nhận diện được hình dáng Việt Nam

**2. Cập nhật VietnamMap.tsx**
- Bỏ MapLibre GL (không phù hợp cho landing page)
- Dùng pure SVG với path chuẩn
- Bỏ markers tên thành phố (chỉ cần outline)
- Không bo tròn

**3. Cập nhật VietnamMap.module.css**
- Bỏ bo tròn (border-radius: 0)
- Giữ animation floating đơn giản
- Glow effect đẹp mắt
- Kích thước phù hợp với hero section

**4. Cập nhật LandingPage.module.css**
- Điều chỉnh `.vietnamMapWrapper` nếu cần

### Files thay đổi
1. `apps/web/src/components/common/VietnamMap.tsx` - SVG path chuẩn
2. `apps/web/src/components/common/VietnamMap.module.css` - Styles đơn giản
3. `apps/web/src/pages/LandingPage.module.css` - Tinh chỉnh nếu cần

### Mục tiêu cuối
- Bản đồ Việt Nam outline đơn giản, sạch sẽ
- Nằm giữa hero section
- Animation floating nhẹ nhàng
- Không có markers/tên thành phố
